🔒 Secure Messenger

End-to-end encrypted messaging app

About: Zero-knowledge server architecture. Your messages are encrypted on-device using NaCl (X25519 + XSalsa20-Poly1305). The server never sees plaintext.
Installation: 1. Tap the Download button above
2. When prompted, tap "Install"
3. Allow unknown sources if asked
4. App opens after installation

🔐 Security Features

  • End-to-end encryption (NaCl)
  • Zero-knowledge server
  • Device-side key generation
  • Fingerprint-based contact verification
  • No metadata stored
  • Maximum 5 users (private)
