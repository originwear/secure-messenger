TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════════════

Q: Can't find the Anon Key in Settings → API?
A: Make sure you're in the correct project dashboard. Look for "Anon public key"
   or "anon_key" - it's a very long string of random characters.

Q: App won't start after updating .env.local?
A: - Make sure .env.local file is saved
   - Make sure Anon Key is correct (copy/paste exactly)
   - Try: npm install (to reinstall deps)
   - Try restarting the dev server

Q: Getting "Invalid credentials" error?
A: - Double-check Anon Key is copied correctly
   - Make sure there are NO extra spaces
   - Make sure you got "anon key" not "service role key"
