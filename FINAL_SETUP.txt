STEP 1: GO TO SUPABASE DASHBOARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open Chrome
2. Go to: https://app.supabase.com
3. You should see "Your organizations" page (you're already logged in)

════════════════════════════════════════════════════════════════════════════════

STEP 2: CREATE A NEW PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD A: Via Organizations Page
1. Click "+ New organization" button
2. Fill in:
   - Name: "secure-messenger" (or any name you like)
   - Type: "Personal"
   - Plan: "Free - $0/month"
3. Click "Create organization"

METHOD B: Direct Link (If METHOD A doesn't work)
1. Go directly to: https://app.supabase.com/new
2. Follow the same steps as METHOD A

AFTER CREATION:
✓ You'll be redirected to your new project dashboard
✓ The URL will change to something like: https://app.supabase.com/project/[project-id]
✓ You should see the project name in the header

STEP 3: GET YOUR CREDENTIALS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In your project dashboard:

1. Click "Settings" in the left sidebar
2. Click "API" (still in left sidebar, under Settings)
3. You'll see several keys displayed:

   📋 COPY THESE TWO VALUES:

   Project URL: https://[something].supabase.co
   ↳ This starts with "https://" and ends with ".supabase.co"
   ↳ Example: https://abcd1234.supabase.co

   Anon public key: [very long string of characters]
   ↳ This is a long base64-encoded string
   ↳ Example: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

4. Copy both values (use the copy buttons next to each)
5. Keep them somewhere safe for the next step

════════════════════════════════════════════════════════════════════════════════

STEP 4: SET UP DATABASE TABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In your project dashboard:

1. Click "SQL Editor" in the left sidebar
2. Click "New Query" button (top right area)
3. You'll see a blank SQL editor

4. COPY THIS ENTIRE SQL SCRIPT:
   ─────────────────────────────────────────────────────────────

   (Open your project folder)
   → Locate file: SUPABASE_SETUP.sql
   → Open it in Notepad or any text editor

   ─────────────────────────────────────────────────────────────

5. Paste it into the Supabase SQL editor (Ctrl+V)

6. Click "RUN" button (usually in the top right)

7. WAIT for it to complete - you should see green checkmarks or "Success" messages

8. Verify it worked:
   - Click "Table Editor" in left sidebar
   - You should see 3 tables:
     ✓ users

   If you see these 3 tables, STEP 4 IS COMPLETE ✅

STEP 5: UPDATE .env.local
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open File Explorer
2. Navigate to: C:\Users\Device\secure-messenger
3. Find the file: .env.local
4. Right-click → Open with → Notepad

5. You'll see:
   EXPO_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here

6. REPLACE these values:
   
   Line 1: Replace "https://your-project-id.supabase.co" with YOUR Project URL
           Example: https://abcd1234.supabase.co
   
   Line 2: Replace "your-anon-key-here" with YOUR Anon Public Key
           Example: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

7. Save the file (Ctrl+S)

8. IMPORTANT: Don't commit this file to git - it contains secrets!

STEP 6: TEST THE APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open PowerShell or Terminal

2. Navigate to the project:
   cd C:\Users\Device\secure-messenger

3. START THE APP:
   
   OPTION A - Android Emulator (if you have one):
   npm run android
   
   OPTION B - Expo Go on your phone:
   npx expo start
   (Then scan the QR code with your phone's camera, open in Expo Go)

4. FIRST TIME SETUP:
   - Click "Sign Up"
   - Enter an email (any email works, e.g., test1@example.com)
   - Enter a password (must have uppercase, lowercase, number, special char)
   - Wait for account creation

5. TEST MESSAGING (with 2 devices/emulators):
   - Create 2 different accounts (test1@example.com, test2@example.com)
   - Device 1: Go to 🔑 Keys tab → Share your fingerprint
   - Device 2: Go to 💬 Contacts tab → Add test1@example.com
   - Compare fingerprints to verify identity
   - Send encrypted messages back and forth!

TROUBLESHOOTING:

Problem: "Table not found" error when signing up
→ Make sure you ran the FULL SUPABASE_SETUP.sql script
→ Check Table Editor - you should see 3 tables
→ Try running the SQL again

Problem: "Invalid credentials" when app starts
→ Double-check .env.local values are correct
→ Make sure there are NO extra spaces
→ Make sure the file is actually saved

Problem: Can't add contacts
→ Make sure both users have signed up first
→ Both users must be created in the same Supabase project
→ Try restarting the app

Problem: Messages not encrypting/decrypting
→ Check the fingerprints match (via Keys tab)
→ Try removing and re-adding the contact
→ Restart the app
